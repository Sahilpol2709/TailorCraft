### **TailorCraft – Custom Blouse Stitching E-Commerce Website**

TailorCraft is an online custom blouse stitching system developed by Sahil Suryakant Pol at the University of Mumbai. TailorCraft is designed to provide users with a seamless experience in selecting and ordering custom blouse designs. With TailorCraft, customers can explore various blouse categories, choose price ranges, place orders, make online payments via Razorpay, and even receive cashback in their wallets. The platform demonstrates the integration of modern web technologies to create a fully functional and user-friendly custom tailoring solution.

### **Features**

- **User Authentication**: Allows users to sign up, log in, and manage their accounts.
- **Blouse Category Selection**: Customers can select from various blouse categories for stitching.
- **Payment Integration**: Offers secure online payment methods for order completion using Razorpay.
- **Admin Panel**: An intuitive dashboard to manage orders, users, and category details.
- **Responsive Design**: The platform adapts to various devices, ensuring a smooth experience on desktops, tablets, and smartphones.

---

### **Technologies Used**

- **HTML**: Defines the structure of the web pages and organizes content.
- **CSS**: Handles the visual design and styling of the user interface.
- **JavaScript**: Adds interactivity and dynamic elements to the platform.
- **PHP**: Powers the backend with server-side scripting.
- **MySQL**: Manages the database to store user data, orders, blouse categories, and more.
- **Razorpay**: Integrates payment gateway for secure online transactions.
- **DOMPDF**: Generates PDF invoices for order receipts.

### **Development Environment Setup**

To set up the development environment for this project, ensure you have the following tools installed:

#### **Prerequisites**

- **Visual Studio Code (VS Code)**: A lightweight, open-source code editor for working with the project files.  
  [Download Visual Studio Code](https://code.visualstudio.com/)

- **XAMPP**: A cross-platform web server solution stack, including Apache, MySQL, and PHP, used for local development.  
  [Download XAMPP](https://www.apachefriends.org/index.html)

#### **Steps to Set Up**

a) **Clone the Repository**:  
   Open your terminal or command prompt and clone the project repository :-
   git clone https://github.com/yourusername/TailorCraft.git

b) **Set up the development environment**:
   Install XAMPP and start the Apache and MySQL services from the XAMPP control panel.
   Download and install Visual Studio Code or your preferred code editor.

c) **Import the Database:**
1. Open **phpMyAdmin** from the XAMPP control panel.
2. Create a new database (e.g., `tailor_management_system`).
3. Import the provided `.sql` file into the newly created database.

d) **Configure Database Credentials:**
1. Navigate to the `config` or `db_connection.php` file in your project.
2. Update the MySQL credentials (username, password, and database name) to match your local setup.

e) **Run the Project:**
1. Open the project folder in **Visual Studio Code**.
2. Make sure **XAMPP** is running.
3. In your web browser, navigate to the project’s `htdocs` directory (e.g., `http://localhost/TailorCraft/Homepage.php`).

f) **Start Developing:**
You're now all set to begin working on the project!
